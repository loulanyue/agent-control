# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within **Agent Control**, please do NOT create a public issue.

Instead, please send an email to `youfy@longjitech.com` or create a private vulnerability advisory on GitHub.

Please provide:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.

We take security issues seriously and will respond promptly to address verified vulnerabilities.
